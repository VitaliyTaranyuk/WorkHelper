# worktask-mcp — MCP-сервер WorkTask

Даёт MCP-совместимому агенту доступ к **задачам** проекта и к отметкам о прохождении
**процесса**. Транспорт — stdio: сервер запускается рядом с агентом и ходит в WorkTask по
HTTP, поэтому учётные данные не покидают машину пользователя.

## Чего здесь нет и не будет: правил

Правила проекта этот сервер **не отдаёт** — и это решение, а не пробел (**ADR-024**).
После ADR-017 и ADR-023 правила доезжают до агента файлами репозитория (`AGENTS.md`,
`.ai/PROJECT_RULES.md`) и работают без сети. Отдавать их ещё и по MCP значило бы завести
второй источник того же содержания — ровно ту ошибку, которую сняли T-107 и ADR-023.

Контракт сервера сужен до того, чего в файлах нет и быть не может: задача, её контекст и
отметка о прохождении этапа.

## Инструменты

| Инструмент | Что делает |
|---|---|
| `worktask_list_projects` | проекты, доступные пользователю |
| `worktask_get_task` | задача по коду вместе с процессом: размер, текущий этап, обязательные этапы |
| `worktask_list_sprint_tasks` | спринты проекта с задачами |
| `worktask_update_task_status` | перевести задачу в колонку доски |
| `worktask_set_process_step` | отметить этап процесса (пусто — снять) |
| `worktask_set_task_size` | размер задачи XS/S/M/L (пусто — снять); понижение фиксируется в истории |

## Настройка

Учётные данные берутся **только из окружения** (**K-33**): сервер их не запрашивает и не
хранит на диске. Без любой из трёх переменных сервер **останавливается на старте** — сервер
без адреса выглядел бы рабочим и молча не отвечал бы ни на один вызов (**W-06**).

| Переменная | Значение |
|---|---|
| `WORKTASK_BASE_URL` | `https://wowoffcata.hlab.kz/work-task/api/v1` |
| `WORKTASK_EMAIL` | почта пользователя WorkTask |
| `WORKTASK_PASSWORD` | пароль пользователя WorkTask |

```bash
npm install
npm run build
```

Подключение к MCP-совместимому агенту (пример для конфигурации вида
`mcpServers` — точный формат смотрите в документации своего агента):

```json
{
  "mcpServers": {
    "worktask": {
      "command": "node",
      "args": ["<путь до репозитория>/mcp/dist/index.js"],
      "env": {
        "WORKTASK_BASE_URL": "https://wowoffcata.hlab.kz/work-task/api/v1",
        "WORKTASK_EMAIL": "…",
        "WORKTASK_PASSWORD": "…"
      }
    }
  }
}
```

## Разработка

```bash
npm run lint   # tsc --noEmit
npm test       # vitest
npm run build  # tsc -b
```

Логика инструментов вынесена в `src/tools.ts` чистыми функциями над клиентом — они
проверяются тестом без сети и без поднятого транспорта. `src/index.ts` только объявляет
инструменты и подключает stdio.
